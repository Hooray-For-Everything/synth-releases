# Hooray For Everything — synth downloads

Experimental Mac instruments for making music. This repository holds reviewed binary downloads and their documentation. It does not contain the instruments' source code or development history.

## Download status

The first public downloads are being prepared. No software asset is available here until its release appears in the Releases list. Each instrument will have a direct product/version link after anonymous download verification.

The initial set is Adaptive Intonation 0.1.0, Tape Polysynth 0.1.0-preview.1, Drum Synth 0.1.0-preview.1, Harmonic Ecosystem 0.1.3-preview.1 and Distant Metal 0.1.0-preview.1. These are early releases/previews, not production-stable software. Full host and listening checks remain pending.

Mac only: Apple Silicon and Intel. Most require macOS 11 or later; Harmonic Ecosystem requires macOS 12 or later. The bundles use local ad-hoc signatures and are not Developer ID signed or notarized.

Read [installation guidance](INSTALL.md), [support guidance](SUPPORT.md), [licensing policy](LICENSE-POLICY.md) and [third-party notices](THIRD-PARTY-NOTICES.txt). Keep the notices with the software.

GitHub's automatic “Source code” ZIP/tarball contains this download repository's documentation only. Choose the named instrument ZIP under its release's Assets to obtain the app and plug-in.
